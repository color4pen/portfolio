## プロジェクト概要

窓口業務をデジタル化するSaaSシステムの開発プロジェクト。バグが収束せず増え続ける炎上案件に火消し役として参画し、夜間も含めたバグ修正を実施。その後、画面デザイン刷新、新規機能開発、リファクタリング提案を担当しました。3-5人の小規模チームをリードしながら自ら実装も担当し、複数ベンダーとの協業体制を構築しました。

## 役割・責任

**役割:** Technical Lead（プレイングマネージャー）

- 3-5人のチームマネジメント
- 技術的な意思決定・アーキテクチャ設計
- エンドクライアントとの直接折衝（工数、リリース、機能設計）
- 協力ベンダーとの協業・見積もり作成
- 実装作業（バグ修正、機能開発）

## 主な業務内容

### 炎上案件の火消し

バグが収束せず増え続ける状態から、夜間も含めた集中的なバグ修正により安定化を実現。

**担当:**
- クリティカルバグの原因調査・特定
- 夜間も含めた修正実装
- テスト・検証
- リリース作業

**成果:**
- 増え続けていたバグを収束
- 重要バグゼロでのリリース達成
- プロジェクトの安定化に成功

### 画面デザイン刷新

既存UIの改善と、協力ベンダーとの協業による画面刷新を推進。

**担当:**
- Technical Leadとして協力ベンダーのエンジニアをリード
- UI/UX設計・レビュー
- layout.tsx等の共通化設計・実装
- Next.js/Reactコンポーネント実装

**課題と対応:**
- layout.tsxでの共通化により一部レイアウト差異が発生
- リリース前のモンキーテストで発覚し修正対応
- 全体としてはUI刷新を完遂

### 新規機能開発

既存機能の補助機能を中心に、テーブル設計から実装まで担当。

**担当:**
- ER図作成・テーブル設計
- 要件定義・見積もり作成
- 設計・実装
- エンドクライアントへの見積もり提出

**成果:**
- 補助機能の追加によりシステムの利便性向上
- 見積もり・提案を通じた機能開発の推進

### リファクタリング・アーキテクチャ改善提案

**実施内容:**
- コードリファクタリングの提案・一部実行
- マルチテナントアーキテクチャの提案（※採用されず、自治体ごとインフラ構築方式に）

## 技術スタック

- **フロントエンド:** Next.js, TypeScript, react-hook-form, Tailwind CSS
- **バックエンド:** Python, AWS Chalice (API Gateway + Lambda)
- **データベース:** PostgreSQL
- **インフラ:** AWS（構築は先方のオペレーションチーム）
- **その他:** Git

## 成果・学び

- **炎上案件の火消し経験:** バグが収束しない状態から夜間作業も含めて安定化を実現
- **複数ベンダーとの協業体制構築:** 協力ベンダーのエンジニアをリードし、見積もり作成から機能開発まで推進
- **エンドクライアントとの直接折衝:** 多層請負構造でありながら、工数・リリース・機能設計でエンドクライアントと直接コミュニケーション
- **SaaSシステムの開発経験:** サーバーレスアーキテクチャ（AWS Chalice）を使った開発
- **小規模チームマネジメント:** 3-5人のチームを技術面・マネジメント面の両面でリード
