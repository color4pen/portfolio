## プロジェクト概要

中古車買取業者向けの買取・オークション情報管理システムの新規開発。既存Webサイトの査定フォームやクライアントとの断片的なやり取りから業務フローを構築し、買取履歴の登録・検索機能、写真管理機能を実装。LINE WORKS連携により現場での利用を想定したMVPを短期間で開発しました。

## 役割・責任

**役割:** 単独開発（1名体制）

- 要件定義の主導
- データベース設計
- フロントエンド・バックエンド開発
- テスト・品質保証
- 上位企業PMとの連携

## 主な業務内容

### 要件定義

詳細な要件定義書が存在しない状況で、断片的な情報を統合して業務フローを構築。

**担当:**
- 既存Webサイトの査定フォーム分析
- LINE WORKSでのやり取り内容から要件抽出
- 買取業務フローの構築
- PMへの確認・合意形成

**成果:**
- 断片的な情報から必要機能を洗い出し
- クライアントMTG機会なしでも進行可能な要件整理
- PMと連携した段階的な仕様確定

### データベース設計

正規化を考慮したスケーラブルなデータベース設計を実施。

**担当:**
- ER図の作成
- テーブル設計（車両マスタ、買取情報、オークション情報の分離）
- リレーション設計
- インデックス設計

**成果:**
- 車両情報と取引情報を分離した拡張性の高い設計
- 買取・オークション両方から車両情報を登録可能な柔軟な構造
- PostgreSQLを用いた効率的なデータモデル

### フロントエンド開発

Next.js App Router + Server Actionsを用いたモダンなフルスタック開発。

**担当:**
- Next.js 14 (App Router) による画面実装
- TypeScript + Tailwind CSSによる型安全でレスポンシブなUI実装
- 日付セクション分けによる視認性の高い一覧表示
- フォームバリデーション
- LINE WORKS連携

**成果:**
- Server Componentsを活用した高速なページレンダリング
- ユーザビリティを考慮した一覧表示（日付セクション分け）
- モバイルフレンドリーなレスポンシブデザイン

### バックエンド開発

Next.js Server Actionsを用いたサーバーサイド実装。

**担当:**
- Server Actionsの実装
- Server Actions用の共通リクエスト/レスポンス基盤の設計・実装
- PostgreSQLとのデータ連携
- エラーハンドリング
- AWS S3署名付きURLを用いた画像アップロード機能

**成果:**
- Server Actionsの特性を活かした効率的な実装
- 共通基盤による保守性の向上
- セキュアな画像アップロード機構

### テスト・品質保証

手動テストによる動作確認を実施。

**担当:**
- テストシナリオ作成
- 打鍵による動作確認
- バグ修正

**成果:**
- 短期間での品質確保
- 主要機能の動作保証

## 技術スタック

- **フロントエンド:** Next.js 14 (App Router), React, TypeScript, Tailwind CSS
- **バックエンド:** Next.js Server Actions, TypeScript
- **データベース:** PostgreSQL
- **インフラ:** AWS (Amplify, S3)
- **連携:** LINE WORKS
- **その他:** ER図設計

## 成果・学び

- **要件構築力:** 断片的な情報から業務フローを構築し、具体的な機能要件に落とし込む能力
- **0→1開発経験:** 新規プロダクトの立ち上げをリードし、MVPを短期間で完成
- **単独開発遂行力:** 設計から実装・テストまで一貫して担当し、スケジュール内に完遂
- **モダン技術への挑戦:** リリース直後のNext.js Server Actionsを実戦投入し、実用的な共通基盤を構築

- **UX視点:** エンジニアとして機能実装だけでなく、使いやすさを考慮した画面設計を実践
